# SPSR - Sistema de Prevenção e Segurança Rodoviária

O SPSR é um sistema de alertas destinado a monitorar, reportar e comunicar sobre eventuais incidentes
nas estradas. O sistema conta com funcionalidades como visualizar um mapa demarcando zonas de risco e de acidentes recentes, alertas climáticos, comunicar acidentes na primeira pessoa e de terceiros, acionar uma central de resposta rápida e ser assistido com base na ocorrência, sugestão de precauções a tomar com base nos acidentes mais frequentes de determinada área e as funcionalidades de alertas são todos baseadas em uma combinação de sons + cores, porque resulta em uma resposta rápida dos instintos primitivos.

*OBS:* *Esse repositório corresponde inteiramente ao front-end do projecto.*
